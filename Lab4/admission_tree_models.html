8. Summary and Discussion (สรุปและวิจารณ์ผลการทดลอง)¶

8.1 สรุปผลการประเมินโมเดล (Model Performance Evaluation)¶

จากการทดลองสร้างโมเดลจำแนกผลการรับเข้าเรียน MBA (Admit = 1, Not Admit = 0) ด้วยวิธี Tree-based ทั้ง 3 โมเดล ได้ผลลัพธ์บน Test Set (Holdout 30%) ดังนี้:

Model Accuracy Precision (Admit) Recall (Admit) F1-Score (Admit) AUC-ROC
Decision Tree 85.21% 44.19% 7.04% 12.14% 0.8450
Random Forest 85.37% 25.00% 0.37% 0.73% 0.8499
Gradient Boosting 83.59% 38.71% 22.22% 28.24% 0.8419

8.2 การวิเคราะห์ปัญหา Class Imbalance และ Accuracy Paradox¶

  1. ปัญหา Class Imbalance: ชุดข้อมูลนี้มีอัตราส่วนผู้ผ่านการคัดเลือก (Admit) เพียง 14.53% ขณะที่ผู้ไม่ผ่านมีสูงถึง 85.47%
  2. Accuracy Paradox: โมเดล Random Forest ให้ Accuracy สูงที่สุด (85.37%) แต่ในความเป็นจริงแทบไม่สามารถทายกลุ่มคนที่ผ่านได้เลย (Recall เพียง 0.37% หรือทายถูกเพียง 1 คนจาก 270 คน) เพราะโมเดลใช้ Default Threshold = 0.5 ซึ่งคะแนนความน่าจะเป็นเฉลี่ยจากต้นไม้ 200 ต้นส่วนใหญ่ไม่แตะ 0.5 ทำให้โมเดลเลือกทายว่า Not Admit เกือบทั้งหมด
  3. โมเดลที่แนะนำ (Best Model): Gradient Boosting เป็นโมเดลที่มีความสมดุลและมีประสิทธิภาพการใช้งานจริงดีที่สุด เพราะให้ Recall (22.22%) และ F1-Score (28.24%) สูงที่สุด สามารถจับผู้ได้รับการคัดเลือกได้ถึง 60 คน
  4. ศักยภาพในการแยกแยะ (AUC-ROC): ทุกโมเดลมีค่า AUC-ROC สูงในระดับ ~0.84 - 0.85 แสดงว่าโมเดลมีความสามารถในการจัดลำดับคะแนนความน่าจะเป็น (Probability Ranking) ได้ดีมาก หากนำไปใช้จริงสามารถปรับลด Threshold ลง (เช่น 0.25 - 0.30) เพื่อดึง Recall ให้สูงขึ้นได้

8.3 ปัจจัยสำคัญที่สุดในการพิจารณารับเข้าศึกษา (Key Drivers / Feature Importance)¶

ผลลัพธ์ Feature Importance จากทั้ง 3 โมเดลสอดคล้องกันอย่างมีนัยสำคัญ:

  • อันดับ 1: gmat (คะแนนสอบ GMAT): มีความสำคัญสูงสุด (~40% - 52%) เป็นตัวชี้วัดที่มีอิทธิพลมากที่สุดในการรับเข้าศึกษา
  • อันดับ 2: gpa (เกรดเฉลี่ย ป.ตรี): มีความสำคัญรองลงมา (~30%)
  • อันดับอื่นๆ: gender, work_exp (ประสบการณ์ทำงาน), และ race มีผลรองลงมาในสัดส่วนรวมกันประมาณ 15% - 20%

8.4 ข้อเสนอแนะเพื่อการปรับปรุงโมเดลในอนาคต (Future Improvements)¶
